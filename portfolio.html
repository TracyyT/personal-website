PERSONAL PROJECT

houspo

June 2026 — Present

Live demo ↗ Code ↗

Developed a home design platform that matches live product listings to users' preferences, using a hybrid recommendation system that blends rule-based scoring with AI-assisted style scoring and adapts to user feedback.

Built "Shop this room," a computer vision feature where users upload a room photo, YOLOE detects each furniture and decor item, and SigLIP 2 embeddings with a learned adapter find visually similar products across a 779-product live catalog, ranked for the user's style and budget.

Improved top-5 retrieval accuracy from 69.3% (CLIP baseline) to 88.8% on 544 catalog test pairs and reached 78.6% on hand-labeled real room photos; deployed the FastAPI vision service on Modal with automatic fallback to regular recommendations.

React Express.js Python PyTorch YOLOE SigLIP 2 FastAPI Modal OpenAI API
