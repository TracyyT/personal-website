# Personal Website — CSCE 331 Project 1

A personal portfolio website created for CSCE 331 at Texas A&M University.

The website introduces my background, projects, technical qualifications, activities, and interests through multiple pages and two different visual styles.

## Website

Live Website: https://people.tamu.edu/~tat2006

## Pages

- **Home** — Introduction and overview
- **Portfolio** — Selected projects and technical work
- **Qualifications** — Resume, technical skills, certifications, and areas of interest
- **Activities** — Experiences, leadership, and interests outside of coursework
- **Sandbox** — AI-generated interactive game featuring my corgi, Bagel

## Features

- Multi-page HTML website
- Two distinct CSS layouts and visual styles
- JavaScript style toggle with persistent theme selection
- Responsive layouts
- Embedded resume
- Interactive AI-generated sandbox page
- External links to professional profiles, projects, and credentials

## Peer Review Feedback

During peer review, I received feedback on the organization, navigation, content, and visual design of my website.

### Suggestions and Changes

- **Make the navigation consistent across pages.**  
  I incorporated this feedback by using the same navigation options on each main page so users can easily move between Home, Portfolio, Qualifications, Activities, and Sandbox.

- **Improve the presentation of projects and experiences.**  
  I reorganized project and activity descriptions to emphasize the technologies used, what I contributed, and what I learned from each experience.

- **Make the website more interactive by making the cards move when hovering.**  
  I incorporated this feedback by adding hover effects and transitions to cards and other interactive elements throughout the website.
